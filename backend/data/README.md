# Data

Downloaded raw files (`raw/`) and regenerated CSVs (`processed/`) are **not committed**. The committed files are:
- `manifest.json`: source URL, licence, sha256 hashes and row counts for each dataset
- `../ml/data/*.py`: the loaders that rebuild everything

```bash
cd backend
python -m ml.data.registry                 # build every dataset
python -m ml.data.registry --only uci_sms_spam
```

## Common schema (`ml/data/schema.py`)

| Field | Type | Meaning |
|---|---|---|
| `text` | str | Raw message |
| `label_binary` | 0/1 | 1 = scam / spam |
| `category` | str or empty | One of the 13 ScamShield categories. **Empty for every real dataset**: none of them has these labels, so none are invented. |
| `source` | str | Dataset name |
| `split` | train / val / test | Fixed split (see each dataset below) |
| `group` | str | Rows with the same group never cross splits (template id for synthetic rows) |

## Datasets

| Name | Kind | Source | Licence | Rows | Used for |
|---|---|---|---|---|---|
| `synthetic_in` | **synthetic** | Generated by `ml/data/synthetic.py` (seed 42) | MIT (this repo) | 8,624 | train / val / test |
| `uci_sms_spam` | real | [UCI SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection), Almeida & Hidalgo 2011 | CC BY 4.0 | 5,159 after de-duplication (5,574 raw) | train / val / test |
| `all_scam_spam_short` | real | [FredZhang7/all-scam-spam](https://huggingface.co/datasets/FredZhang7/all-scam-spam) | Apache-2.0 | 8,389 (≤ 320 chars, not in UCI) | test only (out-of-domain) |

### `synthetic_in`
- Messages are built from 214 hand-written templates in English and romanised Hindi, covering 13 categories. Slots are filled with banks, amounts, names, UPI handles and URLs, and typo/casing noise is added.
- **Split by template:** index % 4 == 3 goes to test, index % 8 == 1 goes to val, everything else to train. Test wordings never appear in training.
- These are not real messages. They encode what the author believes Indian scam SMS look like.

### `uci_sms_spam`
- English SMS from the UK and Singapore (around 2011). "Spam" includes plain marketing, which ScamShield would call *promotional*, not *scam*.
- Exact duplicates (ignoring case and whitespace) are removed **before** the stratified 70/15/15 split (seed 13), so no message appears in two splits.

### `all_scam_spam_short`
- The source mixes 43 languages and is mostly lower-cased, space-tokenised email (Enron, SpamAssassin). We keep rows of at most 320 characters and drop any row whose text also occurs in UCI.
- It is used only as a stress test that is clearly outside the target domain.

## Considered but not used
- `ucirvine/sms_spam` (Hugging Face): the same UCI corpus, and the HF card lists its licence as "unknown". We use the official UCI download instead.
- `gandharvbakshi/SMS-dataset-OTP-OTP_INTENT_Phishing`: Indian OTP/phishing SMS, MIT licence, but **gated**, so it could not be downloaded here. If you get access, add a loader. It would be the most relevant real test set.
- `itsG/smishing-synthetic`: synthetic, and no licence is stated.
